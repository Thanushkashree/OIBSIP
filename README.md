# OIBSIP - Oasis Infobyte Data Science Internship Projects

This repository contains the completed tasks for the Data Science Internship program at Oasis Infobyte.

---

## 📌 Tasks Overview

### Task 1: Iris Flower Classification
- **Description:** Built a Machine Learning model using classification algorithms to categorize iris flowers into Setosa, Versicolor, and Virginica species based on measurements.
- **Files:** [`iris_classification.ipynb`](./iris_classification.ipynb) | [`iris_classification.pdf`](./iris_classification.pdf)

---

### Task 2: Unemployment Analysis
- **Description:** Analyzed unemployment trends across regions using data visualization techniques during the COVID-19 period.
- **Files:** [`unemployment_analysis.ipynb`](./unemployment_analysis.ipynb) | [`unemployment_analysis.pdf`](./unemployment_analysis.pdf)

---

### Task 3: Sales Prediction
- **Description:** Developed a predictive regression model to estimate product sales based on advertising expenditures across various channels.
- **Files:** [`sales_prediction.ipynb`](./sales_prediction.ipynb) | [`sales_prediction.pdf`](./sales_prediction.pdf)

---

## 🛠️ Tools & Libraries Used
- **Python**

- **Matplotlib, Seaborn** (Data Visualization)
